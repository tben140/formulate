# ADR 0000 — Template

- **Status:** Proposed | Accepted | Superseded by [ADR-NNNN](.)
- **Date:** YYYY-MM-DD

## Context

What was true when this came up. Constraints, versions, deadlines, whatever
actually applied pressure. Enough that a reader who has never seen this codebase
can tell why the decision was not obvious.

## Decision

The choice, stated plainly. Present tense.

## Alternatives considered

The options that were genuinely on the table, and why each lost. If nothing was
genuinely on the table, this probably does not need a record.

## Consequences

What this costs, not only what it buys. Include the thing that will look wrong to
someone encountering it later without this context — that is usually the whole
reason the record exists.

## Revisit when

The condition that would make this worth reopening. "Never" is a valid answer;
"when X ships" is a better one.
