Two audiences want opposite things from this project (SHO-119). Hiring
managers read the [case study](../case-study.md) for judgement. Freelance
clients scan for thirty seconds for proof of the one thing they need. These
pages serve the second: each is about one thing, with the proof a client
would look for.

| Piece                                                     | The claim                                                                  |
| --------------------------------------------------------- | -------------------------------------------------------------------------- |
| [Slide-in cart for Liquid themes](cart-drawer.md)         | An accessible cart drawer, with the hard parts done by the platform        |
| [Subscriptions on the product page](pdp-subscriptions.md) | Selling plans and Recharge, priced and worded right on three surfaces      |
| [Accessible commerce forms](accessible-forms.md)          | Labels, errors and announcements that work with a screen reader; EAA-ready |
| [Blog post outlines](blog-outlines.md)                    | Four posts, each from a real problem (SHO-82)                              |

**Recordings** (SHO-81) are on hold. Each page says what its clip should show.

**Brownfield, said out loud.** Everything here was built from scratch, which
hides the more common job: changing a theme someone else wrote. Say it on the
portfolio page: the same patterns drop into an existing Dawn- or Horizon-based
theme, and the theme here was built to Shopify's current standards (theme
blocks, LiquidDoc contracts) so it reads like one a client would already have.
