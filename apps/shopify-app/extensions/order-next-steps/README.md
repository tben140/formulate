# What happens next (thank-you page extension)

On the thank-you page: the dispatch promise, that a tracking link follows by
email, and, when the order has subscriptions, what repeats and how often and
that it can be skipped, paused or cancelled.

Uses the same plan reader as `../subscription-summary`.

**Settings:** _Dispatch promise_ (one sentence, such as "We dispatch orders
within 2 working days."; empty leaves it out) and _Where shoppers manage
subscriptions_ (a full `https://` link).

Wording is factual only, per `docs/claims-wording.md`.
