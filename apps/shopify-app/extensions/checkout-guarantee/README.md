# Money-back guarantee (checkout UI extension)

The 30-day money-back guarantee as a checkout block, where a first-time buyer
decides. Place it in the checkout editor (Settings → Checkout → Customize →
Add app block), beside the order summary or under the pay button.

Words from `../../shared/guarantee.ts`, a copy of the storefronts'
`packages/shopify/src/guarantee.ts`. The merchant can override the heading and
text in the editor; whatever it says must match the refund policy.
